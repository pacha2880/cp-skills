# cp-editorial

A skill for writing editorials and explaining solutions to competitive programming problems from Codeforces, ICPC, AtCoder and training camps.

It sets focus and target length from the problem's rating, solves and (for hard problems) stress-tests the solution before writing, plans the chain of claims from statement to algorithm, and audits the draft against a checklist of common editorial gaps: undefined symbols, values without their origin, missing initial states, and claims without proof. When someone is stuck on a step, it finds the missing link and answers exactly what was asked.

It writes in the language of the request.

Usage: ask for an editorial ("write the editorial for this problem"), paste an editorial passage you don't understand, or ask for camp material on a problem. In Claude Code the skill can also be invoked as `/cp-editorial:cp-editorial`.

See the [repository README](../../README.md) for installation and a full example.
