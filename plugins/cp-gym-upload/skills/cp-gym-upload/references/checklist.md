# Checklist before handing over

## Data

- [ ] Every test passes a validator written from the statement's constraints: ranges, structure (tree, connected…), line counts, parity. Violations in the original are reported, not fixed.
- [ ] Every solution was run on every test locally, and each got its intended verdict.
- [ ] Every solution's output on the samples matches the statement.
- [ ] Statements in all languages (and editorials) were read side by side.

## Polygon, per problem

- [ ] Number of tests and samples as expected.
- [ ] Tags: one MA, the rest as intended.
- [ ] Checker set; TL/ML as decided.
- [ ] Statement in every language.
- [ ] Latest package READY, and no uncommitted changes.
- [ ] Main solution under half the TL.

## Polygon contest

- [ ] Problems in order.
- [ ] `codeforces` has read access.

## Gym

- [ ] Visibility Private; duration, season, type, location, difficulty, website, description and logo set.
- [ ] Every problem renders as HTML in English.
- [ ] Materials uploaded per language.
- [ ] "Ghosts: (N)" shown, and standings match the official scoreboard team by team.

## Hand-over

- [ ] Files in the user's folder: `img/`, statements `.tex`/PDF per language, `*-official.pdf`, `solutions/`, `polygon/`, `ghosts.dat`, logo.
- [ ] Report written in the user's language (SKILL.md §5).
